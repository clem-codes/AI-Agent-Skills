# AI Agent Skills

A personal collection of skills: instruction files that teach AI agents such as Claude how to handle particular kinds of work.

## The skills

- [Dataviz Fundamentals](Dataviz%20Fundamentals/): choosing, building, critiquing or fixing a static chart, map or table, using the principles of Claus Wilke's *Fundamentals of Data Visualization*.
- [Frontend Design for Dashboard](Frontend%20Design%20for%20Dashboard/): designing the interface of a product, tool, dashboard, web app, personal site or small browser game, starting from a clear visual idea and avoiding generic AI-looking design.
- [Information Is Beautiful](Information%20Is%20Beautiful/): turning data, research or ideas into concept-driven, editorial-quality charts and infographics, inspired by David McCandless's *Information Is Beautiful*.
- [Refactor](Refactor/): tidying up or restructuring code without changing what it does, in small steps that are checked as you go.

## Using a skill

Each folder holds a `SKILL.md` file in the Agent Skills format: a name and description at the top, followed by the instructions.

To use one with Claude Code, copy its folder into `~/.claude/skills/`.
